# Ameyalli agent context

Ameyalli is a public research-only repository. It contains no product source,
no executable package, and no claim of peer review or certification.

Read `README.md`, `THESIS.md`,
`docs/research/methodology/evidence-methodology.md`, and
`docs/research/adr/editorial-conventions.md` before changing content. Preserve
the Spanish study, the A/B/C evidence labels, the privacy boundary around
living people, and exact source provenance.

## Repository invariants

- `THESIS.md` is the public study and remains written in Spanish.
- Governance, bibliography, provenance, and technical documentation are
  English.
- Git history is evidence; do not rewrite published research history.
- GitHub is a publication and collaboration surface, not factual authority.
- AI systems may assist research and editing but cannot create evidence.
- Source records are individual; no untyped bibliography dump is authoritative.
- Changelog, TODO, graph, and validation outputs are deterministic projections.
- No code, package manifest, or product-language surface is added without a
  repository decision.
