# Documentation index

## Purpose

Provide the canonical entry point for every durable documentation family in
Ameyalli.

## Contents

- [`bibliography/`](bibliography/README.md) records cited sources, tools,
  standards, legal identities, provenance, and bibliography decisions.
- [`legal/`](legal/README.md) records repository legal interpretation and
  decisions.
- [`research/`](research/README.md) records methodology, research decisions,
  and supporting papers.
- [`technical/`](technical/README.md) records integrations, verification, and
  technical decisions.
- [`TODO.md`](../TODO.md) indexes open and completed work items.
