# Bibliography

## Purpose

Provide one durable record for every cited work, tool, standard, format, and
legal identity used by the repository.

## Owns

External identity, repository use, provenance, and evidence boundaries.

## Does not own

Research truth beyond the evidence stated in each individual record.

## Contents

- [`sources/`](sources/README.md) indexes the 30 works cited by `THESIS.md`.
- [`tools/`](tools/README.md) indexes integrated tools and hosted platforms.
- [`standards/`](standards/README.md) indexes formats and specifications.
- [`legal/`](legal/README.md) indexes license identities.
- [`provenance/`](provenance/README.md) records assistance and verification.
- [`adr/`](adr/README.md) owns bibliography-specific decisions.
