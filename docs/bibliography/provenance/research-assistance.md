# Research assistance provenance

## Status

Active historical record.

## Origin

The initial draft drew on two research reports produced with deliberately
different instructions. One report received candidate morphological analyses
to confirm or refute. The other received no candidate solution and was asked
to derive and falsify the analysis independently. Neither report was treated
as a source.

## Systems used

ChatGPT, Gemini, Claude, Cursor, and Model Context Protocol tools assisted with
research, drafting, comparison, editing, or repository operation. Firefox and
ripgrep supported source access and local search. Git and GitHub retained the
accepted repository history.

## Admission rule

Agreement between assistants is a discovery signal, not independent evidence.
A result entered the study only after direct source verification or explicit
reasoning tied to admitted sources. Disagreement created a verification task
and was never resolved by averaging outputs.

## Known limitation

Exact model versions and complete early prompts were not retained. Future work
must record them when they materially affect reproducibility. The durable
record is the accepted Git change and its supporting source record, not the
transient assistant response.
