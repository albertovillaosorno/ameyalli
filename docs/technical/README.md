# Technical governance

## Purpose

Index repository operation, validation, and integration contracts.

## Owns

Git, GitHub, Cursor, Jig, generated evidence, and validation behavior.

## Does not own

Research conclusions, source authority, or licensing analysis.

## Contents

- `integrations/` documents operator-facing systems.
- `verification/` documents reproducible validation.
- `contracts/` owns editorial and machine contracts.
- `adr/` records technical decisions.
